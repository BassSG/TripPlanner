# Assets

- `assets/chiang-mai.jpg`: Ash Edmonds, sunset outside Chiang Mai. [Original on Unsplash](https://unsplash.com/photos/landscape-photo-of-mountains-mXBZo6PvjMk), [Unsplash license](https://unsplash.com/license). Downloaded as a 1400px JPEG for reliable, local hosting and offline use.
- `assets/icon.svg`, `icon-192.png`, `icon-512.png`: original TripPlanner compass/map-pin artwork. PNGs generated from the same artwork in `scripts/icons.ps1`.
- Interface icons: original inline SVG paths in `src/app.js`.
- Fonts: Manrope and Noto Sans Thai, served by Google Fonts, with local system fallbacks when offline.
